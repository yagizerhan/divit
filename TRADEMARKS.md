# Name and Logo Policy

The project's **source code** is free under GPL-3.0-only (see `LICENSE`). This policy covers only the project's **name and logo**. Its purpose is to let users tell the official builds apart from modified copies.

## Allowed (no permission needed)

- Talking about the project, writing reviews or tutorials: "Drawing with Divit", "How to install Divit".
- Redistributing unmodified official builds without changing the name or logo.
- Stating compatibility for your own project: "compatible with the Divit protocol".
- Crediting the source in forks: "derived from the Divit project".

## Needs permission / not allowed

- Publishing a **modified** build under the Divit name or logo. Forks must use a **different, non-confusing** name and logo.
- Using the name or logo in a way that suggests the product is made or endorsed by the official project.
- Registering a domain name, app-store listing or package name containing the name (e.g. `divit-pro`, `divit-plus`).
- Using the name or logo on a copy that is **sold**, even together with its source code.

## Official builds

- Official downloads: the GitHub Releases page of the project repository (and the app stores it is listed on).
- Every release is published with SHA-256 checksums.
- The application ID (Android `applicationId` `io.github.yagizerhan.divit`) is used only by official builds. Forks must use a different ID.
